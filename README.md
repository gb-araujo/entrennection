## Sobre o projeto

Entrennection e uma plataforma criada para apoiar microempreendedores que precisam ampliar rede de contatos, encontrar parcerias e acessar oportunidades de desenvolvimento. O projeto foi desenvolvido como trabalho academico e explora uma experiencia web voltada a networking profissional.

A proposta e conectar empreendedores por area de interesse, permitir interacoes dentro da plataforma e estruturar um caminho para aprendizado, mentoria e colaboracao.

## Objetivos

- Aproximar microempreendedores com interesses complementares.
- Facilitar networking e criacao de parcerias comerciais.
- Oferecer base para conteudos, mentorias e consultorias.
- Incentivar crescimento colaborativo e empreendedorismo local.

## Funcionalidades

- Cadastro de microempreendedores.
- Perfil com informacoes do negocio, area de atuacao e interesses.
- Busca de oportunidades de parceria.
- Proposta de plano Plus com aulas, mentorias e consultorias.
- Rede social interna com postagens, noticias e conexoes.

## Requisitos

- Node.js 18 ou superior
- NPM

## Rodando localmente

```bash
git clone https://github.com/gb-araujo/entrennection.git
cd entrennection
npm install
npm start
```

A aplicacao abre em `http://localhost:3000`.

## Scripts

| Comando | Descricao |
| --- | --- |
| `npm start` | Inicia o ambiente de desenvolvimento |
| `npm test` | Executa testes do Create React App |
| `npm run build` | Gera build de producao |
